# 🎨 Solomoji

Transform your WhatsApp chat memories into beautiful emoji posters.

## 🚀 Quick Deploy

### Netlify (Recommended)
1. Go to [Netlify](https://netlify.com)
2. Drag and drop this folder or connect your GitHub repo
3. Deploy automatically - no build step required!

### GitHub Pages
1. Push files to a GitHub repository
2. Go to Settings > Pages
3. Select source branch
4. Your site will be live at `https://yourusername.github.io/repo-name`

### Other Platforms
- **Vercel**: Just drag & drop the files
- **Firebase Hosting**: `firebase deploy`
- **Surge.sh**: `surge .`

## 📁 Files

- `index.html` - Main website
- `style.css` - Styling
- `script.js` - Emoji extraction & PDF generation
- `netlify.toml` - Netlify configuration
- `_headers` - Security headers

## 🔒 Privacy

All processing happens client-side. No chat data is sent to servers.

## 🛠 Features

- ✅ Drag & drop file upload
- ✅ WhatsApp chat parsing
- ✅ Emoji extraction
- ✅ PDF poster generation
- ✅ Mobile responsive
- ✅ Privacy-first design
